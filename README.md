A collection of tools and prototypical features for a Synthesizer Product. This repo is also used as a means to explore application of Sound synthesis frameworks for the features developed and tested.

## 2. Frameworks

### pywdf

`pywdf` is a recently developed and published framework in python that allows engineers to model Virtual Analog circuits for analog music and sound making. [Source Link](https://www.dafx.de/paper-archive/2023/DAFx23_paper_23.pdf)
